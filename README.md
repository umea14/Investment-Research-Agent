# Investment-Research-Agent
A real-world financial analysis system powered by agentic AI
The system is designed to:
- Plan research and delegate tasks to specialized agents.
- Retrieve and analyze stock prices, financial statements, and news.
- Apply prompt chaining, routing, and evaluator–optimizer workflows.
- Evaluate findings, refine analyses, and retain lessons for future runs.
Built with Python, Google Colab, OpenRouter, and Yahoo Finance.
